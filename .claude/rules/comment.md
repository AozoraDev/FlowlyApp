# rule: comment

生成业务部分代码时，配上简洁凝练的简体中文注释。

## 规则

- **业务代码必须配有简洁凝练的简体中文注释**，说明"做什么，为什么这么做"，而非逐行翻译代码。
- 组件/函数上方用 `//` 或 `/** */` 注释描述职责和关键逻辑；复杂条件分支、状态转换、副作用处添加行内注释。
- 基础 UI 组件（`components/ui/*`）和基础设施（`lib/*`）可保持全英文，不加中文注释。

## 示例

```tsx
// 好：说明意图
// 从缓存中读取用户偏好，若无则返回默认值
function getUserPreferences() { ... }
```
